# 椰挞（Yeta）内容研究

对抖音创作者「椰挞进步没！」（抖音号 43101871626）公开作品的内容研究，重点观察个人 IP 表达、个人服务销售、选题与内容节奏。

## 目录

- `研究查看器.html`：交互式研究查看器，含40条作品的时间线、研究记录、机器转写与OCR材料。
- `catalog/`：作品日期、标题、公开链接、压缩与核验清单。
- `transcripts/`：40条完整机器ASR材料和字幕、源帧时间戳索引，以及已有OCR材料。
- `reports/`：逐片研究记录、总研究与近两个月内容节奏/服务销售/选题分析。
- `tools/`：本地查看服务与按需提帧工具。
- `开始阅读.md`、`MATERIALS_README.md`：材料说明与使用方式。

## 视频文件

本仓库完整收录研究包的非视频材料；为控制传播范围，未上传 `videos/` 中的40个完整视频。视频仍保留在原研究包 `E:\DouyinResearch\43101871626_compact\videos`。作品链接列于 `catalog/视频索引.csv`。如果本地查看器需要播放视频，可将合法取得的对应视频按索引中的ID放入 `videos/<视频ID>.mp4`。

## 研究范围

主页中的2条置顶作品和最近38条非置顶作品，共40条，按真实发布时间排序，覆盖2026年5月21日至9月29日。近两个月分析使用其中2026年8月2日至10月2日窗口内的15条作品。机器转写存在错漏，未逐字校订；分析仅讨论公开可见内容，不验证创作者或客户的业绩陈述。
